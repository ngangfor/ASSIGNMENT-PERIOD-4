# Travel Agency Project – Horizon

A Java object-oriented booking system for a travel agency, built as part of the OOP 1.5 module.  
This project demonstrates core OOP principles, collection usage, unit testing, and responsible AI-assisted development.

## 📂 Project Structure
```text

├── src
│   ├── Trip.java
│   ├── Customer.java
│   ├── Booking.java
│   ├── TravelAgency.java
│   └── Main.java
├── tests
│   └── TravelAgencyTest.java
├── UML Diagram
│   └── travelagency-uml.png
├── Reflection Video.mp4
└── README.md
```

## ✨ Key Features
- **Trip Management**: Create trips with destination, price, and long‑distance flag.
- **Customer Registration**: Age validation based on birthdate.
- **Booking Logic**: Automatic under‑18 restriction for long‑distance trips.
- **Cancellations**: Integrated 10% cancellation fee logic.
- **Analytics**: Show popular destinations based on booking counts.
- **Testing**: JUnit tests for all critical business rules.

## 🚀 How to Run
1. **Clone the repository**:  
   `git clone <your-repo-url>`
2. **Open Project**: Open in IntelliJ IDEA or your preferred Java IDE.
3. **Run Demo**: Execute `Main.java` to see the system in action.
4. **Run Tests**: Execute `TravelAgencyTest.java` with JUnit 5 to verify logic.
